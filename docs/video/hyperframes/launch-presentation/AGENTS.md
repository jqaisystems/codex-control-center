# Launch Presentation HyperFrames Project

This project renders the compact Codex Control Center launch presentation.

## Commands

```powershell
npm run lint
npm run validate
npm run inspect
npm run render
```

`npm run render` writes a draft MP4 to the ignored `video-output/` folder at
the repository root.

## Safety

- Use fake/demo screenshots only.
- Keep the JQAI Systems logo small in the top-left corner.
- Do not show private paths, raw prompts, raw logs, account data, `.env` files,
  auth files, or tokens.
- This project does not publish, upload, commit, stage, or push anything.
