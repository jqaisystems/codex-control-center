# Browser Walkthrough Script

Target length: 90-120 seconds
Format: 16:9
Style: real local browser workflow wrapped in a clean branded frame
Safety: temporary demo database, fake Codex home, fake workspace, no real account data

## Voiceover

### 0:00-0:08 - Hook

This is Codex Control Center as a local browser workflow: observe first, choose
one workspace, queue read-only work, then review before sharing.

Caption: `A browser walkthrough of the safe local workflow`

### 0:08-0:25 - Dashboard

Start on the Dashboard. System Mode controls how active the dashboard should be,
Usage Remaining is best-effort local metadata, and Readiness Score explains the
setup and selected workspace health.

Caption: `Dashboard: mode, usage, readiness, sessions`

### 0:25-0:43 - Tasks

Open Tasks. Register only the folder you want inspected, use a Safe Starter
Task, keep the sandbox read-only, and queue the task for approval.

Caption: `Choose a workspace, start read-only`

### 0:43-1:01 - Results

After a task completes, Results gives safe summaries, duration, tool counts,
token metadata when available, and suggested next read-only follow-up tasks.

Caption: `Results: safe summaries and next actions`

### 1:01-1:18 - Vault Health Report

Vault Health Report explains the readiness findings with safe relative paths by
default. Full local paths stay hidden unless the user explicitly reveals them.

Caption: `Vault report: relative paths by default`

### 1:18-1:33 - Skills

The Skills page shows discovered skills and plugin-provided skills with safe
labels. Path reveal is available, but this public demo keeps full paths hidden.

Caption: `Skills stay visible without exposing full paths`

### 1:33-1:48 - Publish Readiness

Before sharing, Publish Readiness checks docs, fixtures, ignore coverage, Git
review state, and the public safety scan. It does not publish, commit, stage,
push, upload, or contact GitHub.

Caption: `Publish checks without publishing anything`

### 1:48-1:52 - Close

That is the safe loop: observe locally, launch deliberately, review results, and
share only after the checks are ready.

Caption: `Local-first. Metadata-only. Approval-gated.`
