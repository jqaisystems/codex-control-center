# Launch Presentation Script

Target length: 45-60 seconds
Format: 16:9
Style: compact product overview with generated draft voiceover and captions
Safety: fake screenshots only, no private paths, no raw prompts, no logs

## Voiceover

### 0:00-0:07 - Hook

A local Control Center for Codex.

Codex is powerful, but daily work needs visibility, organization, and safer
launch controls.

Caption: `A local Control Center for Codex`

### 0:07-0:15 - Local-First Promise

Codex Control Center brings local metadata into one dashboard.

Observation does not require an API key, and the app never reads Codex auth
files.

Caption: `No API key required for local observation`

### 0:15-0:24 - Dashboard

See system health, usage remaining, readiness scoring, recent sessions, and
local tool activity without exposing private prompt or output content.

Caption: `Dashboard: health, usage, readiness, sessions`

### 0:24-0:33 - Task Safety

When you launch work, every task starts in an approval queue.

Read-only is the default, workspace-write is explicit, and full danger access
is blocked in V1.

Caption: `Approval-gated tasks, read-only by default`

### 0:33-0:41 - Results

Results stay focused on safe summaries, durations, tool counts, and next
actions.

Caption: `Safe summaries, not raw logs`

### 0:41-0:49 - Publish Readiness

Before sharing, Publish Readiness checks docs, fixtures, ignore coverage, and
safety scan status.

It does not publish, commit, stage, push, upload, or contact GitHub.

Caption: `Publication checks without publishing anything`

### 0:49-0:56 - Close

Codex Control Center version zero point one: local observability,
approval-gated control, and no API key required for local observation.

Caption: `github.com/jqaisystems/codex-control-center`
